# Specimens

`index.json` is the canonical specimen list. The first registered specimen is [chatgpt.com](chatgpt-com/v0001/analysis.md).

A queued specimen has a stable slug and sanitized origin, but no version. Processing the first supplied snapshot creates `<slug>/v0001/record.json` and `analysis.md`, followed by further numbered directories on later captures. Each version is a snapshot **within this research project**, not the website's own release version.

All public files contain original research metadata and reviewed analysis only. Source ZIPs, copied pages, saved scripts, styles, network traces and **raw** asset inventories are not stored here. Sanitized ordinal reference metadata may be published after review. Private inventories belong under ignored `.work/`. See [research protocol](../docs/RESEARCH.md).
