This gallery catalogs **project-authored technical research**, not captured website pages or republished source assets. Its canonical machine-readable catalog is [index.json](index.json).

## Published research

### chatgpt.com — Saved-page structural study, v0001

A scope-limited examination of an authenticated ChatGPT page saved as standalone HTML. The research covers DOM structure, client bootstrap mechanisms, CSS tokens, accessible markup, resource references, browser state indicators, and a clear record of missing runtime and external-bundle evidence.

- [Read the human-readable dossier](../specimens/chatgpt-com/v0001/analysis.md)
- [Explore the machine-readable ontology](../specimens/chatgpt-com/v0001/record.json)
- [Inspect the sanitized 31-resource reference inventory](../specimens/chatgpt-com/v0001/resource_inventory.json)
- [Review task dispositions](../queues/tasks.json)

**Scope:** one capture, not a verified reconstruction of the entire ChatGPT product. Four tasks are not observable from the submitted source. The ZIP, HTML source, browser state, account-linked data, original site assets, and conversation content are **not** included.

**Provenance:** original research derived from a user-supplied standalone saved HTML snapshot. **Publication rights:** original project commentary and structured ontology under MIT; no third-party capture assets are relicensed.

Further specimen captures become separate internal versions. New gallery entries require a technical review and a rights/privacy check.

It separates **source syntax and candidate relationships** from live, verified execution, and includes scope-bounded CSS, state, media, accessibility, network, and security observations.
